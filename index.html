FROM SPARE MAC TO SECOND DISPLAY

A few clicks.
A whole new desktop.

  1. 01

    Open MacPair on both Macs.

    Download the ZIP, unzip it, and open MacPair.app on each Mac. Both need macOS 13 or later. One download works on Apple Silicon and Intel.

  2. 02

    Give your second Mac a new role.

    On that Mac, choose Display Mac. It starts waiting and shows a six-digit pairing code. MacPair remembers the role next time. Leave Wi-Fi switched on.

  3. 03

    Pair. Then make yourself some room.

    Your main Mac searches automatically. In the connection card, enter the code once, choose Extend or Mirror, and click Connect. Keep both apps open to reconnect without a code. Reopening either app requires a new code.

First time opening MacPair?

MacPair is locally signed, not an Apple-notarized release. If macOS blocks it, use the app-specific System Settings → Privacy & Security → Open Anyway option.

Allow Local Network on both Macs. Your main Mac also needs Screen Recording: grant it, then quit and reopen MacPair. The display Mac needs no Screen Recording permission. Pairing credentials stay only in memory; MacPair does not access Keychain. Reopening either app requires a new six-digit code. Remove a session pairing under Settings → Session pairings → Forget. Use the main Mac’s keyboard and trackpad; audio and display-side input are not included.

Release & testing notes

The earlier prototype was user-tested successfully across two Macs on different Wi-Fi networks. Standalone operation without joining any Wi-Fi network is still unconfirmed; the reported “no Wi-Fi” attempt failed.

Version 0.1.10 removes Keychain access and keeps pairing credentials only in memory. Reopening either app requires a new code. The bounded video feedback, overlapping encode/send work and stage timings are unchanged. Generated encrypted Retina video and delayed-receiver checks passed locally. Wireless responsiveness, discovery cards, and Retina sizing still need a two-Mac retest. Both updated peers target up to 60 fps; older peers retain 30 fps. These are targets, not measured guarantees. Mirror fits within 1280 × 800; Extend keeps the display Mac’s negotiated pixel dimensions.

Virtual displays use an experimental macOS interface. Pairing has not had an independent security review. Discovery uses availability, not physical distance. Both apps must be running. Audio, display-side controls, and automatic reconnection are not included. See the guides inside the download for test steps and compatibility notes.
