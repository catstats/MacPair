# MacPair branding

These two user-supplied originals are stored without image changes:

- MacPair Dual Monitor Logo.png: wide logo / wordmark.
- MacPair_Icon.png: transparent 1024 × 1024 app icon source.

scripts/build-icon.sh creates the standard macOS icon sizes and packages them as MacPair.icns during each build. Info.plist selects that resource as the application icon.
